# 世界与内容基线

**适用场景**: 需要新增帮派、地盘、角色模板或调整世界观语调时.

## 主题语调

- 表层是武侠帮派权谋, 底层是荒诞黑色幽默.
- 角色认真争权夺利, 系统结果可以滑稽、反讽、令人哭笑不得.
- 文本应像江湖传闻或报刊短讯, 短句、强动词、重后果.

## 核心实体

| 实体 | 用途 |
|------|------|
| Person | 角色, 承载欲望、性格、状态、记忆、关系和战斗属性 |
| Gang | 帮派, 承载成员、财政、声望、地盘和策略倾向 |
| Territory | 地盘, 承载收益、守备、特色事件和控制者 |
| Item | 物品, V1 可选, 用于武器、毒药、账本等事件道具 |
| Event | 事实源, 表达发生了什么以及影响哪些实体 |

## 角色模板

| 模板 | 主要能力 | 典型欲望 | 典型风险 |
|------|----------|----------|----------|
| 帮主 | 统率、声望 | 权力、求生 | 被暗杀、误判奖惩 |
| 军师 | 谋略、谈判 | 求名、权力 | 卷款、离间、背锅 |
| 打手 | 战斗 | 名声、复仇 | 冲动误伤、挑衅决斗 |
| 探子 | 谍报 | 贪财、求生 | 叛变、双面卧底 |
| 账房 | 财务 | 贪财、平安 | 挪用资金、被威胁举报 |
| 杂役 | 低成本劳力 | 求生、发财 | 被欺负后爆发 |

## 地盘内容原则

- 每个地盘至少定义收益、风险标签、特色事件池.
- 高收益地盘必须带来更高冲突或负面事件概率.
- 官府衙门不作为普通可占领地盘, 只作为压力源和事件目标.

## 内容新增要求

新增内容时必须回答:

1. 它影响哪些数值或关系?
2. 它能触发什么事件?
3. 它在日志里如何被玩家理解?
4. 它是否会导致不可控崩盘?
